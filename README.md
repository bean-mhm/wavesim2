# wavesim2

wavesim2 allows you to run 2D and 3D wave simulations. It is written in Python
and comes with the following features:

- GPU-accelerated using a compute shader for the simulation and a ray marching shader for rendering

- Programmable excitations in the wave field

- Programmable camera POV

- Realtime preview

- MP4 export

- Physically based units

# Running

wavesim2 uses [uv](https://github.com/astral-sh/uv) for package and project
management. It's super easy to learn and use (check out its `README.md`), so I
won't clutter this document with redundant instructions.
